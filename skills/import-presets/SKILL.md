# Import presets

The reference project sets these by hand and is inconsistent (report 02, counts from a shell sample, VERIFIED as counts, intent INFERRED). No importer enforcement exists; add presets or an `AssetPostprocessor`.

## Textures (Android override)
- ASTC: 6x6 default, 4x4 for UI/hero art, 8x8 for backgrounds. Max size by use (256-1024 typical, 2048 only when justified). Crunch off.
- `isReadable` OFF (the sample had 14 accidental ones; each doubles memory). Streaming mips only if needed. sRGB on for colour, off for normal/mask maps. Mipmaps on 3D textures.

## FBX
- Import lights, cameras and blend shapes OFF unless used (26 sampled models imported blend shapes needlessly). No secondary UV. Weld vertices on.
- `isReadable` only for meshes used as combiner sources (`mesh-scene-combiner`).
- Mesh compression policy per project; index format auto.
- Prefer meshes generated by Editor scripts into `.asset` for vibe-coded worlds (FBX as reference art only).

## Audio
- SFX: decompress on load, mono. BGM/long: streaming, load in background. Vorbis; quality ~0.5 is a target (INFERRED; sample had 1.0 almost everywhere).

## Enforce
Unity Presets or `AssetPostprocessor.OnPreprocess*` by folder (`Assets/_Art`, `Assets/_Game/Audios/Sfx|BGM`); validate with an EditMode test that lists violations. These are defaults: override when the reference project or art needs differ, and note why.
