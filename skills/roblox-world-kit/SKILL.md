# Roblox world kit

Design from report 18 (mining + proposal). Everything marked INFERRED is unproven in the Editor and on a device; `STUD_M = 0.28` is UNVERIFIED (check against a door/avatar ratio from the reference).

## Units and assembly
- One constants class (`RobloxUnits`): `STUD_M` default 0.28, `WORLD_SCALE` from the GDD. Studs stay square regardless of metres. No studs in gameplay code (see Roblox defaults in `roblox-to-unity-map` when it exists).
- Calibrate: door 4x7 studs, avatar 5-6 studs (knife-tower capsule 1.7 m / 0.28 = 6.1).
- Grid: X/Z integer studs, Y 0.5-1; platforms >= 8x1x8; jump gaps <= 0.8 x computed from jump height and speed; stair rise <= 1 stud; slopes <= max stable slope (50 deg). Chunk 32-48 m. Kill plane default -500 studs.
- Map is generated from a spec so it can be regenerated; hand edits in an overlay file.

## Palette (DATA) and surfaces (DATA)
- `Palette_Roblox` asset: ~64 named BrickColor-like entries with stable ids, sRGB hex + cached linear, categories. Hex values must be sampled from reference frames (placeholders otherwise). GDD refers to ids ("Bright red"). Tint themes by id.
- `Factory_RobloxSurface`: surface id -> flags, atlas slot, default tint, physics material, footstep sfx; read by baker, gameplay and validator. Roblox materials map: Plastic = stud top; SmoothPlastic = flat; Neon = neon+emission; Glass/ForceField = alpha material; Grass/Sand/Brick/Wood/Metal... = atlas cell; Checker = math; Lava/conveyor = scroll. No Unity Terrain.

## Kit pieces
Prefabs under `Prefabs/RobloxKit/` generated by `procedural-mesh-generator`, one mesh + the shared material, pivot bottom centre, whole-stud sizes: floors (8/16/32 plates, road, lava strip, checker), walls/pillars/fences/arches/door frame, ramps and stairs, obby pieces (truss, spinner, moving/disappearing plate, jump pad, checkpoint, kill brick), decor (tree, bush, rock, cloud, sign, torch, crate), shells (cage, shop stall, spawn). Variants differ by palette id only.

## Validate (`roblox-world-validate`, Editor tool to build)
Material census; SRP Batcher compatibility; vertex data linear and bits valid; mesh budgets per tier (`world_budget_check.py`, see `mobile-urp-lighting-baseline`); integer-stud sizes and jump gaps; no MeshCollider on chunk visuals; navmesh referenced; palette delta-E; lighting preset; idempotent re-bake.

Pipeline: `one-material-world-shader`, `vertex-color-baking`, `procedural-mesh-generator`, `mesh-merge-baker`.
