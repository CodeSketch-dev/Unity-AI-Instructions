# Building the GUID reference index by hand (what `dead_assets_proof.py` does)

1. guid -> path: for every `X.meta` under `Assets/`, read the first ~400 bytes, match `guid: <32 hex>`; the asset path is the meta path minus `.meta`. Folder metas count too (needed for ancestor checks).
2. references: for every text-serialized file (`.unity .prefab .asset .mat .controller .anim .overrideController .mixer .shadergraph .spriteatlas .playable .inputactions .asmdef .json .meta` plus `ProjectSettings/*` and `Packages/manifest.json`), find every `guid: <32hex>` and `GUID:<32hex>` (asmdef references use the second form). Map guid -> set(referrers). A `.meta` referring to a guid (texture importer sprite sheets, default references) counts as a referrer of that guid but is attributed to its asset.
3. A file is unreferenced when no referrer other than itself exists. Also collect `Assets/...` path strings inside serialized files (some tools store paths, not guids).
4. Fixpoint: referrers that are themselves unreferenced do not count; repeat until stable (max 4 passes). This finds chains (dead prefab -> its dead material -> its dead texture).
5. Code references: every string literal in `.cs`. A literal equal to the file name, name without extension, or containing the asset path makes the asset UNKNOWN (loaded by name). A literal ending in `_` or `/` that prefixes the asset name (`"Biome_"`) is a prefix load: runtime code -> UNKNOWN, Editor-only code -> allowed (a builder regenerates it).
6. Protected: anything under `Resources/`, `StreamingAssets/`, `Plugins/`, `Editor Default Resources/`, `Gizmos/`, and scenes listed in `EditorBuildSettings.asset`.
7. Ancestor folders: if a parent folder's guid is referenced from outside the folder (Addressables group entry, SpriteAtlas packable, folder reference), every child is UNKNOWN.
8. Binary-serialized files (no `%YAML` header): text scans see nothing. Search the raw bytes for the candidate guid in three layouts (raw 16 bytes, per-dword nibble-reversed big-endian, per-dword nibble-reversed little-endian). Validate on a project by taking a text copy of the same scene and checking that its known guids are found in the binary one (on the verified project the little-endian nibble-reversed layout matched 396 of 396). Better: convert the scene to Force Text.
9. Packages: for each manifest dependency read `Library/PackageCache/<name>@*`: namespaces declared, asmdef names, script guids; used if a `using` of its namespaces exists in project code, an asmdef references it, a project asset references one of its script guids, or another package depends on it. Absence of all is only LIKELY-DEAD.

Limits to state in the report: reflection by computed names, Addressables labels loaded by label, UnityEvents wired by name in text, native plugins, and packages used only through scripting defines are invisible to the scan. The Editor re-check (open every build scene, Play 5 s) is the second half of the proof.
