# Provenance
Derived from a read-only catalog of the Knife Tower style reference project (88 UI/service prefabs, scripts read, git history reviewed). KT used the earlier CodeSketch package; SketchEngine is the upgraded form with the same concepts. Names such as Quest_Focus_Pointer, Currency_Spread, Shop_All, Result_Revive_Checkpoint, Daily_Login are the reference's names: treat them as example identifiers, and re-verify every API in the installed package before use.
Key numbers worth keeping: popup open/close 0.1 s (settings 0.3/0.2); dim alpha 0.7-0.98; hand pointer pulse scale 1 -> 1.1 over 0.5 s; count-up 0.7 s OutCubic unscaled; bar punch scale 1.2 for 0.05 s; revive countdown 10 s with a 1.25 s delayed "no thanks"; spread timings: sequence 0.5, back 0.09 x 0.5, scale 0.5, fly 0.3 after 0.5.
