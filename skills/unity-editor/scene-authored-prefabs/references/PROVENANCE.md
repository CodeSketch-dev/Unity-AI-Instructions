# Provenance
Rules distilled from the Knife Tower style reference project (managers, chunks and UI pages are prefabs placed in scenes; roots are a mix of prefab instances and plain containers; the player is one prefab with nested GUI, camera and character prefabs; 73 prefab variants for skins and per-mode players; popups created through the popup manager) and from owner standing orders (scene-authored, Edit Mode UI, no runtime-created managers). The reference runs CodeSketch v1; this skill teaches the SketchEngine form. Folder, naming and StaticBus content that used to live here moved to `project-structure-layout`, `static-bus-events` and `ui-page-item-prefab`.
