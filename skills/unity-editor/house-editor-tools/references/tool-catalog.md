# Tool catalog (what each tool does, how to run it, port notes)

U = universal, O = optional, G = game-specific (rebuild per game, do not copy). Sizes are of the reference implementations.

| Tool | Class | Purpose and run | Port notes / pitfalls |
|---|---|---|---|
| Scene optimizer orchestrator | U | One menu + hotkey (Ctrl+Shift+B) bakes everything a scene precomputes: combiner renderer groups, distance-cull lists, NavMesh, waypoints; then `MarkSceneDirty`. Needs one optimizer object in the active scene. Callable from MCP `script-execute`. | Loop over an `IEditorBakeable` interface instead of hard-coding game components (`samples/Scene_Optimizer.cs.txt`). Only the ACTIVE scene's optimizer is used; save the scene afterwards; blocks the Editor (progress bar, no cancel). |
| Mesh scene combiner bake | U | Buttons "Bake Renderer Groups" / "Clear Baked"; a skip-tag component marks dynamic subtrees (also honoured by the collider extractor). | Do not run a second runtime combiner on the same objects. See `mesh-scene-combiner`. |
| Distance cull manager fetch | U | CullingGroup with one distance band; button collects sprite/text renderers from listed prefabs into serialized lists. | Exclude always-visible indicators. See `culling-group-distance`. |
| Data and play menus | U | Clear PlayerPrefs / game data (persistent path files) / caches / all, open data folder, pause F2, slow F3, reload F5, screenshot F4, open build scene N (Shift+1..9). | Screenshot must not write into `Assets/`. Add a dev-save backup/restore (a wipe-only tool loses test saves). |
| QA ink dump + audit + fix | U (UI games) | Play: `Qa_InkDump.Run(path)` writes live UI rects (host, text ink bounds, icon rects, owning prefab path); screenshot same frame; `ink_audit.py` measures ink vs face; Edit Mode `Apply Ink Fixes` applies per-prefab corrections, max 2 automatic attempts per target. | Coupled to node naming (`PopupRoot`, Header, Title, Backdrop). Runtime-built UI has no prefab path and cannot be fixed (skipped, counted). See `ui-ink-audit`. |
| Prefab Replace | U | Replaces every child with a mesh by a prefab instance matched by name prefix or mesh name, copies local transform and sibling index, renames old to `[OLD_REPLACED]` and disables; buttons delete old / reactivate / remove missing scripts. Works on scene objects and prefab assets. | Matching is by mesh name; "remove missing scripts" mutates unrelated objects on every call: make it an explicit button. |
| Collider Extractor | U | Clones non-trigger BoxColliders of a prefab/scene into a child `Collider` object, skipping skip-tagged subtrees, so visual meshes can be combined without losing collision. | BoxCollider only; overwrites an existing child of that name. |
| Material Collector / Match Finder | U | Collect unique project materials under scene parents and move/copy to a folder (GUIDs kept); list GameObjects using a material under a root. | Move changes paths: commit first. Skips scene/built-in materials silently. |
| Audio Config Generator | U | Drag clips, set prefix (`Sfx_`), output folder; creates or updates one config asset per clip by path. | Detect same clip name in two folders; accept dragged folders; swap in the installed audio config type. |
| Localization glyph preloader / exporter | U (Localization + TMP) | All keys x locales resolved from the string table, RTL-fixed, characters added to the matching font atlas, missing glyphs logged; export the unique character list per font. Workflow: font Dynamic -> run -> switch Static -> save. | Needs a generated key class, a font-per-locale factory, RTL library only for Arabic. Tables must be loaded in the Editor. |
| Mock toggle | U | Menu with check mark toggles an editor-only mock (native ads, IAP, subscription). | Pattern for every monetisation flow; the real SDK path must still be tested on a device. |
| Character component copy | O | Copies components between rigs by bone name; two-pass so joints resolve to bodies. | Good ragdoll transfer pattern. |
| Debug vertex colours | O | Logs distinct vertex colours and counts of the selected mesh. | Cheap, helps vertex-colour worlds. |
| Nav link creators | O | Scene-view click placement of off-mesh links with layer-mask surface picking and a list panel. | Only for traversal games. See `nav-traversal-link-tool`. |
| Texture auto compressor, batch instancing, find unused textures, find missing components | U | Per-folder compression and max-size sets for default + Android; list materials and enable GPU instancing; scene/prefab hygiene finders. | Often shipped by the framework package: check the installed one first. |
| Id rebuilder | G idea | Fills empty ids and fixes duplicates but never changes an existing unique id (keeps old saves valid). | Copy the rule for any scene-authored id. |
| Vendor SDK partials | U | Project-owned `*.Dev.cs` partial classes extend a vendored SDK (init hooks, next-scene index) so updates never conflict. | Never edit the SDK folder. |
| MCP wiring | U | Package + per-project `.mcp.json` URL; per-tool enable list in user settings; scripting defines added to every target. | `UserSettings/` ignored; never copy host tokens. |
| One-shot migrations | G | Clone/patch prefab content once. | Delete after use; never `[InitializeOnLoadMethod]`. |
| Unauthenticated command bridge | do not port | Local socket that accepts menu-run and create-script commands. | Local code execution surface; use MCP. |

Agent config: keep a hand-written `AGENTS.md` (project, packages, folder structure, naming, coding style, reference caching, mobile performance, architecture rules, a "Future rules" append area, safe command permissions) and a managed block that imports the shared instructions; ignore generated skill copies and per-machine permission lists.
