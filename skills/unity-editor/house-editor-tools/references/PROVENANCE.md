# Provenance

Catalog derived from an inventory of the studio's "Knife Tower style" reference project: 17 first-party editor files (3.7k lines, no asmdef), the framework package's own editor tools (about 27 menu items, 4.2k lines) and a QA ink loop. Findings carried over: no CI, no hooks, no build/version script, no tests in the reference; an unauthenticated local command bridge existed there and must not be ported; two tools mutate assets on every reload or rename package-cache folders and are anti-patterns. The pre-commit hook sample was exercised in a temporary git repository (rejects missing .meta and added missing-script markers, accepts a clean commit). The C# samples were written against Unity editor APIs but NOT compiled in a project; the CI workflow was not run.
