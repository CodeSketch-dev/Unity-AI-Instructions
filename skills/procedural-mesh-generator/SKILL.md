# Procedural mesh generator

Pattern from thunder-break-egg (reports 11, 18): meshes generated by Editor scripts into `.asset`; FBX stays reference art only.

## PartSpec (data, not code)
`{ shape (Block|Wedge|Cylinder|Sphere|CornerWedge), sizeStuds, colorId, surfaceId, studTop, rotation, pos, name }` in JSON or a ScriptableObject map spec. The spec is the authoring source: regenerate from it; hand edits go in an overlay file (a re-run once overwrote hand recolouring).

## Geometry and UV rules (design, INFERRED)
- Block = 24 vertices (4 per face, hard normals) so box mapping is exact. Cylinder 12 segments, sphere 8x6 on low-end. Index format UInt32 if > 65,000 vertices.
- `uv0` = world units on the two axes perpendicular to the normal / 1 stud, origin snapped to integer studs so neighbours align; flip winding when `determinant < 0` (mirrors). Bake scale into vertices, not the transform.
- Stud-top flag only on faces with normal.y > 0.7. Snap sizes to whole studs, positions to 0.5 stud.
- Voxel meshes: emit exposed faces only.

## Tool hygiene (VERIFIED incidents)
- Output folder per segment (`Assets/_Game/Meshes/RobloxWorld/<Segment>/`), idempotent; delete + recreate assets; one segment per MCP call.
- Iteration caps on every loop (a runaway used 31 GB); never `InstantiatePrefab` on a nested-prefab child (30 GB hang); `MarkSceneDirty` + `SaveAssets`; print a count report (parts/verts/tris/bounds).
- Naming `_Generator`, `_Builder`, `_Wiring`; menu "Only" variants for safe partial runs.

Colour and shader contract: `vertex-color-baking`, `one-material-world-shader`. Merge and scene bake: `mesh-merge-baker`.
