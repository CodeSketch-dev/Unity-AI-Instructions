# Provenance

The dim-hole technique, numbers, two-layer blockers, step driver and quest arrow come from the studio's Knife Tower style reference game (read-only prefab/script study; visual result not observed in Play). `prefab-dumps/` are snapshots of that game's hierarchy and material. The `images/` folder and the `reference-implementation/*.example-game.cs.txt` files are historical iterations from an earlier port in another studio project (names stripped); filenames containing `before` or `too-far` are failure examples. Do not copy their project contracts, class names, save dependencies or raw-input behaviour.
