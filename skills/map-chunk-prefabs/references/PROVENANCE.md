# Provenance
Derived from the Knife Tower style reference project (levels, stages and tower floors are prefabs dragged into minigame scenes under plain containers; no additive scenes, no streaming, no runtime level spawning; optimizer stack with mesh combiner and distance culling) plus the owner's ruling that maps are real authored objects (never rebuilt at runtime from records) and the object-budget numbers, which are soft defaults chosen for low-end mobile, not measured reference values. The reference's largest chunk prefab (22 MB) and its 12 MB hand-built scene are cited as warnings.
