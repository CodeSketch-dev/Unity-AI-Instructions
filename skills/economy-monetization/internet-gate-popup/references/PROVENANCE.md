# Provenance

Flow, endpoints, the 15 s / 5 s / 5 s timings, the remote flag, the paid-user bypass and the "root stays active" pitfall come from the studio's Knife Tower style reference game (read-only study; verified by code, not run). The SketchEngine `Internet` module behaviour (auto-start, `SkipCheck`, `IsEnabled` set only after the first tick, factory-provided popup) was read in the installed package source. The timeline note: the paid-user exemption was added a day after the popup shipped, so design the bypass in from the start.
