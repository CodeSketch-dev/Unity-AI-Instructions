# Provenance

Gate, two trigger sites, good/bad paths and the persisted-vs-session data trick come from the studio's Knife Tower style reference game (read-only study, verified by code). Its known defects (a never-incremented counter, a commented-out iOS call, no cooldown) are corrected here as studio improvements and marked as such. The store-review wrapper API was read in the installed SketchEngine package (`Modules/Appstore`).
