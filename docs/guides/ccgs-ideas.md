# Idea-only notes (not skills yet)

Seeds worth turning into skills when a project needs them.

- qa-plan: derive a test plan per feature from acceptance criteria, grouped by change class (see regression-suite).
- smoke-check: a 2-minute boot-to-first-reward Play pass run before every longer test.
- balance-check: re-simulate the economy after any number change and compare pacing with a stored baseline.
- content-audit: list planned vs shipped content (items, zones, pets, strings) and flag gaps.
- live-ops: calendar of events, offers and seasonal themes with rollback switches.
- hotfix: minimal-diff flow for a live bug: reproduce, fix, targeted test, ship, backport note.
- day-one-patch: low-risk fixes gathered during certification, shipped right after launch.
