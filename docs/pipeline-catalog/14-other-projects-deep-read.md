### 3.1 When DOTS is worth it on low-end mobile (answer)

Evidence: the only DOTS use in all projects is `ProjectDawn Agents Navigation` as a NavMesh/avoidance backend with a hybrid MonoBehaviour character on top [V]. Characters stay GameObjects with KCC; ECS only owns path + local avoidance, synced each `LateUpdate` (`body.Velocity`, `loco.Speed`) [V `AI_Pathfinding_AgentNavigation.cs`]. They also had to add guards for destroyed entities (`HasEntityPath` check before `OnLinkTraversal`) [V comment in file], and an A* alternative (`AI_Pathfinding_Astar`) exists in knife-tower [V catalog 04].

Recommendation [I, labeled as a design decision, not measured]:
- **Default: NO DOTS.** Use `NavMeshAgent` or the existing `AI_Pathfinding` abstraction. A 1-day clone has <= ~30 simultaneously active agents (steal-an-egg bots, break-and-steal bots, Steal-a-Pet bots): all use plain `NavMesh` (`House.AgentAreaMask`, `BotMover`) [V].
- Use the hybrid Agents Navigation backend only when the Roblox design needs >100 chasers with avoidance (swarm/horde, "hungry worm" style crowds). Cost: pulls Entities + Burst + Collections into build size and domain-reload time, needs IL2CPP and Burst working on the device, and a unity-version-sensitive embedded package (4.4.6 here). Not measured on a low-end device anywhere in these repos.
- Never use ECS for rendering or for per-pet income (pets at 5-30 count tick fine in one manager `Update`).

- Model [V]: `House { slotPets[], slotCollect[], ownerType (None/Player/Bot), IsLocked, LockedByBot, navAreaIndex, lockRadius 8 }`, `SlotPet`/`SlotCollect` (per-slot coin accumulation), `Pet : BaseObject {petConfig, petName, rarityType, petPrice, cashPerSecond, moveSpeed 3, State PetSlotState}`, `PetConfig` SO (name, rarityType 0-5, sprite, `petPrice`, `cashPerSecond`, `isWatchAds`, vfx). 25 pet SOs (rarity counts: Common 6, Uncommon 4, Rare 6, Epic 4, Legendary 3, Mythic 2 [V grep]); sample `AngryShonky67` (Uncommon) price 30,000, 200 cash/s; cash/s values seen: 2, 3, 5, 7, 9, 25, 30, 35, 40, 55, 250, 300, 500, 750, 2100 [V].
- Spawn [V `ModeStealPet`]: pets walk a belt from `pointStart` to `pointEnd` every 3 s; rarity weights **Common 50, Uncommon 30, Rare 15, Epic 4, Legendary 1, Mythical 0.1**; first 10 spawns restricted to Common/Uncommon (early-game help); prefabs pooled via `GameController.ObjPool`; prefabs bucketed by rarity once at `Start`.
- Save [V `DataSaveStealPet`]: `DataAllGame { coinTotal, dataHouses[ {dataSlotPets[ {hasPet, petName, coin} ], lock state/time} ], collectedPetNames }`; offline coin via `CashPerSecondOf(petName)`.
- Steal [V `BotThief`]: bot picks a victim slot (pet standing in a slot of another house), runs 3 phases `GoToVictim -> CarryHome -> WaitOutside`; grabs within 2.5 m, victim slot is reserved, victim (if bot) chases/attacks (`BotAttacker`); touching own `HouseCollider` drops pet into free slot; fall/timeout returns the pet; `stealCooldown 30 s`, `taskTimeout 20 s`, `maxPlayerThieves 2`, `playerPriorityChance 0.65`; static counter reset with `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]` [V].
- **Lock mechanic** [V `House`]: locking a house removes that house's NavMesh area bit from every non-owner bot's `areaMask` (`AgentAreaMask`), owner and all pets keep `NavMesh.AllAreas`; bot-locked houses enable a physical wall against the player. Time-limited with a countdown label. Elegant, cheap: no per-frame checks beyond a lock timer.
- `BotBrain` modes: `Wander, Collect, Attack, Steal` [V].
- Trust rank: Tier 3 code, **Tier 2 for the design pattern (belt spawn + slot house + lock via NavMesh area)**.

## 8. What to design fresh (not found locally) - pet systems

Because no local project implements follow / evolve / craft [V grep], the pipeline needs a recipe built from the verified pieces:
- **Follow**: reuse `Pet_Carrier._followSharpness` smoothing (exponential approach to a trailing anchor + sine bob) [V pattern]; for N followers use ONE manager tick with ring-buffer of the player's past positions (I); never one `Update` per pet.
- **Equip**: hotbar of uids (ride-a-pet `DataInventory.hotbar`) or `_hotbarSlot` + `Active` flag (steal-an-egg/break-and-steal); equipped set recomputes income via an event (`EventPetsChanged`) [V].
- **Evolve/craft** (Roblox pet games use "N of same -> next tier / mutation"): model as a recipe SO `{ inputPet, count, outputPet|mutation, cost }` + a `Data_*` op that removes N records and adds one; map onto existing multiplier ladders (steal-an-egg mutations 1/1.25/2/2.5/3.5/5x, break-and-steal 1/2/2.5/3.5x) [I].
